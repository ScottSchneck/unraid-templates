# Unraid templates

Unraid Community Apps templates by Scott Schneck.

| App | Template | Project |
| --- | --- | --- |
| Block Party | [templates/block-party.xml](templates/block-party.xml) | [ScottSchneck/block-party](https://github.com/ScottSchneck/block-party) |

Install from **Apps** in the Unraid web interface: search for *Block Party*.

Support for each app is on its project page. The templates are MIT licensed;
each app has its own license.
